WEB115 / PARALLAX

只要上下捲動，鏡頭就會沿著二維路線移動

00 / DEPARTURE

不是橫向捲軸，
是鏡頭向右走。

你仍然只是在上下捲動。這個頁面把捲動進度換算成 SVG 路徑上的座標，再反向移動整個世界。

向下捲動

01 / HORIZONTAL

當 Y 不變，
只有 X 增加。

Y = 620

路徑的第一段是一條水平線。攝影機焦點從左往右走，所以畫面中的內容看起來向左滑過。

02 / THE TURN

Q 指令把直角
磨成一個彎。

Q 2750 620, 2750 1020

SVG 的 quadratic curve 同時改變 X 與 Y，讓鏡頭自然轉向，而不是突然跳到另一條軸線。

03 / VERTICAL

Y

X 固定，
Y 持續增加。

同一個進度控制器，現在讓鏡頭往下走。內容仍在原本的 DOM 座標上，沒有切換成另一套頁面。

04 / DIAGONAL

X 與 Y
一起改變。

ΔX +1600ΔY +1100

斜向移動不是旋轉網頁，而是每一幀同時更新世界的水平與垂直位移。

05 / ARRIVAL

一條垂直捲軸，
走完整個二維世界。

  1. 01建立固定 viewport
  2. 02把內容放進大型 world
  3. 03用 SVG path 定義鏡頭路線
  4. 04以 scroll progress 取得路徑座標
  5. 05反向 translate3d() 整個 world
