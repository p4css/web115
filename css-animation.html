Attention animation / 注意力動態

Make the eye pause.

這是一份常見網頁動態的互動標本。上半部用 mouseover 或鍵盤 focus 觸發；下半部則在物件頂端抵達視窗的 50vh 時觸發。

01 / Hover 02 / Scroll

Trigger 01 / Mouseover

Hover to attract attention.

把游標移到每張卡片，或按 Tab 聚焦。效果應短、明確，而且不妨礙讀者理解內容。
